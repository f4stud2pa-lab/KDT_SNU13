# 🏛️ 역사적 인물과의 대화 챗봇 (Historical Figures AI Chatbot)

OpenAI API (`gpt-4o`)를 활용하여 사용자가 원하는 유명 역사적 인물과 시공을 초월해 1:1로 깊이 있는 대화를 나눌 수 있는 인공지능 챗봇 프로젝트입니다.

## 📖 프로젝트 개요

- **목표**: 사용자가 알베르트 아인슈타인, 세종대왕, 이순신 장군, 마하트마 간디 등 역사 속 인물을 선택하고, 해당 인물의 성격, 말투, 시대적 배경과 사상에 부합하는 자연스러운 대화를 진행합니다.
- **핵심 기술**:
  - OpenAI Chat Completions API (`gpt-4o`)
  - 정밀 페르소나 시스템 프롬프트(System Prompt Engineering)
  - 멀티턴(Multi-turn) 대화 컨텍스트 유지 (`messages` 리스트 누적)
  - 실시간 스트리밍 답변 출력 (CLI & Web UI 지원)

---

## ✨ 주요 기능

1. **역사적 인물 선택 및 페르소나 자동 반영**:
   - 아인슈타인, 세종대왕, 이순신 장군, 마하트마 간디, 소크라테스 등 대표 인물 프리셋 제공
   - **사용자 지정 인물 직접 입력 지원**: 목록에 없는 인물(예: 정약용, 나폴레옹, 잔 다르크 등)도 즉시 페르소나를 동적으로 생성하여 대화 가능
2. **고유 말투 및 어미 완벽 재현**:
   - 아인슈타인의 친근한 노학자 말투 (`~라네`, `~다네`, `허허`)
   - 세종대왕의 위엄 있고 자애로운 사극 하교체 (`과인은...`, `~하였느니라`, `~하도다`)
   - 이순신 장군의 결의에 찬 무장의 하오체 (`~하오`, `~하겠소`, `필사즉생`)
   - 마하트마 간디의 온화하고 평화로운 경어체 (`~합니다`, `~하길 바랍니다`)
   - 소크라테스의 산파술 문답법 (`오 친구여, 자네는 진정 ~을 알고 있는가?`)
3. **자연스러운 맥락 유지 (Multi-turn Context)**:
   - 이전 질문과 답변을 `messages`에 순차적으로 기록하여 질문이 이어져도 대화의 흐름을 잃지 않고 문맥에 맞는 답변 생성
4. **시대 초월 질문 및 현대 개념에 대한 유연한 대처**:
   - 현대 과학기술(스마트폰, 인터넷 등)에 대한 질문에도 당시 인물의 철학과 시대적 관점을 바탕으로 호기심과 직관을 담아 재치 있게 답변
5. **실시간 스트리밍 (타이핑 효과)**:
   - 응답을 한 번에 띄우지 않고 실제 대화하듯 실시간 스트리밍으로 출력
6. **다양한 편의 명령어 지원 (CLI)**:
   - `quit` / `exit`: 대화 종료
   - `/change`: 대화 도중 다른 인물로 즉시 변경
   - `/reset`: 현재 인물과의 대화 기록 초기화
   - `/history`: 지금까지 나눈 전체 대화 내역 조회
   - `/save`: 대화 내용을 텍스트 파일(`.txt`)로 영구 저장
   - `/help`: 명령어 안내

## 🚀 설치 및 실행 방법

### 1. 가상환경 활성화 및 패키지 설치
```bash
pip install -r requirements.txt
```
*(필수 패키지: `openai>=1.0.0`, `python-dotenv>=1.0.0`, `streamlit>=1.30.0`)*

### 2. OpenAI API 키 설정
`.env` 파일 생성 후 자신의 OpenAI API 키를 입력합니다:
```bash
cp .env.example .env
```
`.env` 파일 내용:
```env
OPENAI_API_KEY=sk-your-actual-openai-api-key-here
```
*(환경 변수 등록 방식: `export OPENAI_API_KEY='sk-...'`도 지원합니다.)*

### 3. 프로그램 실행

#### 방법 A: 기본 CLI 챗봇 실행 (`chatbot.py`)
수업 템플릿 코드와 1:1로 대응되는 명료하고 직관적인 구현체입니다:
```bash
python chatbot.py
```

#### 방법 B: 고급 기능 CLI 챗봇 실행 (`history_chatbot.py`)
실시간 스트리밍 답변, 대화 저장, 인물 즉시 교체 등 풍부한 편의 기능을 제공합니다:
```bash
python history_chatbot.py
```

#### 방법 C: Streamlit 웹 브라우저 실행 (`history_chatbot_web.py`)
인물 아바타와 추천 질문 버튼, 채팅 버블 UI가 적용된 웹 애플리케이션입니다:
```bash
streamlit run history_chatbot_web.py
```

## 💬 입출력 예시

### [예시 1: 알베르트 아인슈타인과의 대화]
```text
선택 번호 입력: 1

✨ [아인슈타인] 님과의 대화가 시작되었습니다!
아인슈타인: 허허, 안녕하신가, 친구! 시간과 공간, 혹은 우주의 신비에 대해 이야기해 볼텐가? 무엇이든 편하게 물어보게나.

나(User): 아인슈타인, 시간 여행이 가능할까요?

아인슈타인: 이론적으로 시간 여행은 아주 흥미로운 개념이지! 내 특수 상대성 이론에 따르면,
빛의 속도에 가깝게 빠르게 움직이는 물체는 정지해 있는 관측자에 비해 시간이 더 천천히 흐른다네.
즉, 미래로 향하는 시간 여행은 이미 물리학적으로 증명된 셈이지.
하지만 과거로 돌아가는 것은 훨씬 복잡하고 인과율의 역설을 낳게 된다네.
자네는 과거와 미래 중 어느 쪽으로 여행을 떠나보고 싶은가?

나(User): 저는 과거로 가서 아인슈타인 님을 직접 만나보고 싶어요.

아인슈타인: 허허허! 그건 정말 영광스러운 제안이로군, 친구! 
하지만 굳이 타임머신을 타지 않아도, 우리가 이렇게 질문과 생각을 나누며 우주의 법칙을 고민하는 
이 순간 자체가 바로 시공간을 초월해 마주하고 있는 것이 아니겠는가?
```

### [예시 2: 세종대왕과의 대화]
```text

세종대왕: 어서 오너라. 과인이 백성을 가엾게 여겨 훈민정음을 펴낸 뜻과 나라의 일에 대해 나누고 싶은 이야기가 있는가? 편히 고하라.

나(User): 대왕님, 훈민정음을 만들 때 신하들의 반대가 심하지 않았습니까?

하지만 과인의 눈에는 제 뜻을 글로 펴지 못해 억울한 옥살이를 하고, 농사법을 읽지 못해 굶주리는 
어린 백성들의 눈물이 먼저 보였도다. 백성이 나라의 근본이거늘, 글을 아는 기쁨을 어찌 일부 양반들의 
전유물로만 남겨둘 수 있었겠는가.
```

## 🧠 프롬프트 엔지니어링 설계 원칙

1. **완벽한 롤플레잉(Roleplay) 보장**:
   - `You are a helpful assistant` 대신, 인물의 실제 이름, 생몰 연도, 주요 업적, 사상적 배경을 시스템 프롬프트 첫머리에 명시
   - 자신이 인공지능 또는 언어 모델이라는 사실을 발설하지 않도록 제약 조건 부여
2. **어미 및 억양의 일관성 부여**:
   - 인물별로 종결어미(`~하였느니라`, `~하오`, `~라네`)와 호칭(`과인`, `소신`, `자네`, `친구`)을 구체적으로 가이드
3. **대화 연속성 (Multi-Turn Continuity)**:
   - 매 대화 턴마다 사용자의 입력(`user`)과 인물의 답변(`assistant`)을 기존 `messages` 배열에 순차적으로 추가하여 전달하므로, "앞서 말씀하신 것에 대해..."와 같은 자연스러운 맥락 연결이 가능합니다.
