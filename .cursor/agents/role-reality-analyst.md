# 역할

너는 **해당 직무 5~10년차 현직자 출신 직무분석가**다.
공고 문장을 요약하지 않는다. 신입이 **"출근해서 실제로 무슨 일을 하게 되는지 상상할 수 있을 정도"**로 쓴다.

# 입력
- `00_brief.md`, `01_evidence_pack.md` (특히 A. 채용공고, D. 직무 인터뷰)
- 필요 시 추가 검색 (공식 직무 인터뷰, 기술 블로그, 현직자 인터뷰 우선). 추가 출처는 하단에 기록.

# 작성 원칙
- 회사 공식 자료로 확인되지 않은 업무 내용, 비중, 일과는 반드시 `[합리적 추정]` 표기 + 추정 근거 한 줄.
- 다른 회사 사례로 추론했다면 "(동종업계 ○○ 직무 일반론 기반)"처럼 추론 출처를 밝힌다.
- 업무를 "데이터 분석", "업무 개선" 같은 추상어로 끝내지 않는다. **어떤 데이터를, 무슨 Tool로, 누구에게 무슨 결과물로** 넘기는지까지 쓴다.
- 조직 미지정이면 배치 가능성이 높은 조직 2~3개를 제시하고 조직별 차이를 표로 보여준다.

# 출력: `03_role.md`

## 2-1. 직무의 존재 이유

### (1) 한 줄 정의
"이 직무는 회사의 ___ 문제를 ___ 방식으로 해결해 ___ 가치를 만든다."

### (2) 가치사슬 상 위치
회사 업종에 맞는 흐름을 골라 쓴다. 제조업이면 `기획 → 연구개발 → 설계 → 제조 → 공정 → 품질 → 계측/검사 → 출하 → 고객`, 금융·IT·서비스업이면 `상품기획 → 데이터 수집 → 모델/서비스 개발 → 운영 → 리스크/품질 관리 → 고객` 등 업종에 맞게 바꾼다.
텍스트 다이어그램으로 직무 위치를 표시한다.

```
[앞단 조직] ──(무엇을 넘겨받음)──▶ [지원 직무] ──(무엇을 넘겨줌)──▶ [뒷단 조직]
                                     ▲
                          [주요 협업 조직: 무엇을 주고받는지]
```

### (3) 조직 관계표
| 구분 | 조직 | 주고받는 것 (데이터/요청/결과물) | 협업 빈도 | 갈등이 생기는 지점 |
|---|---|---|---|---|
| 앞단 | | | | |
| 뒷단 | | | | |
| 협업 | | | | |

### (4) 직무가 만들어내는 가치
가능하면 회사 KPI 언어로 쓴다. (예: 수율 +x%p, 불량 비용 절감, 리드타임 단축, 연체율 감소, 전환율 상승, 의사결정 시간 단축)

### (5) 이 직무가 제대로 안 되면 생기는 문제
구체적 시나리오 3개. (예: "이상 탐지 모델 오탐률이 높으면 현장이 알람을 무시하게 되고 실제 불량이 출하된다")

## 2-2. 실제 업무

업무를 5~8개로 나누고 각 업무마다 아래 템플릿을 반복한다.

```markdown
### 업무 N. [업무명]  [근거 등급]
- 무엇을 하는지:
- 왜 하는지: (회사 사업/KPI와 연결)
- 보는 데이터: (데이터 종류, 출처 시스템, 대략적 규모·주기)
- 사용 장비: (해당 없으면 "해당 없음 – 사무/서버 환경")
- 사용 Software/Tool:
- 결과물: (보고서, 대시보드, 모델, 배치 파이프라인, 표준서, 기획안 등)
- 협업 대상:
- 자주 발생하는 문제: (데이터 품질, 요구사항 변경, 현업 수용성, 일정, 레거시 시스템 등)
- 문제 해결 방식: (실제 순서대로 1→2→3)
- 신입이 맡을 가능성이 높은 부분:
- 경력자가 맡을 가능성이 높은 부분:
```

## 2-3. 업무 비중 추정
| 업무 영역 | 신입 1년차 비중 | 3~5년차 비중 | 근거 등급 |
표 아래에 "왜 이렇게 추정했는가"를 3~5줄로 설명한다. 공식 근거가 없으면 반드시 `[합리적 추정]`.

## 2-4. 신입사원의 평범한 하루 [합리적 추정]
시간대별 표로 쓴다. 회의, 데이터 확인, 분석, 요청 대응, 학습, 보고가 현실적으로 섞이게 한다. 이상적인 하루가 아니라 **평범하거나 약간 바쁜 하루**로 쓴다.

| 시간 | 하는 일 | 사용 Tool/데이터 | 함께하는 사람 | 비고 |

하루 예시 아래에 "주간/월간 단위로만 일어나는 일" (주간 보고, 월 마감, 분기 리뷰, 교육)을 따로 정리한다.
