# [실습 4] 역사적 인물과 대화를 나누는 AI 챗봇

OpenAI API (`gpt-4o`)를 활용하여 사용자가 역사 속 위인(아인슈타인, 세종대왕, 이순신 장군, 마하트마 간디 등)과 고유의 말투 및 시대적 배경을 반영하여 1:1로 대화를 나누는 챗봇 프로그램입니다.

---

## 📌 실습 목표 및 세부 요구사항

1. **사용자 입력**:
   - 질문을 자유롭게 입력 가능
   - 대화할 역사적 인물을 선택 가능 (목록 선택 및 사용자 직접 입력)
2. **프로그램 기능**:
   - 선택된 인물의 성격, 말투, 시대적 배경과 사상을 반영한 답변 생성
   - 멀티턴(Multi-turn) 대화 기록 유지를 통해 연속 질문 시에도 이전 대화의 맥락 유지
   - `quit` 또는 `exit` 입력 시 자연스럽게 대화 종료
3. **출력**:
   - 실제 역사 속 인물이 대답하는 듯한 자연스럽고 시대상이 반영된 답변 출력

---

## 📂 파일 구성

- **`chatbot.py`**: 수업 템플릿 코드 기반의 직관적인 콘솔 챗봇 (인물 선택 + 페르소나 주입 + 맥락 유지)
- **`history_chatbot.py`**: 확장 기능 탑재 CLI 챗봇 (실시간 스트리밍 출력, 대화 파일 저장 `/save`, 인물 실시간 변경 `/change`, 대화 초기화 `/reset`)
- **`history_chatbot_web.py`**: Streamlit 기반 웹 UI 챗봇 (인물별 아바타, 추천 질문 버튼, 말풍선 대화 인터페이스)
- **`requirements.txt`**: 필요한 파이썬 라이브러리 목록
- **`.env.example`**: OpenAI API Key 환경 변수 설정 예시 파일

---

## 🚀 실행 방법

### 1. 패키지 설치
```bash
pip install -r requirements.txt
```

### 2. API Key 설정
`.env` 파일을 생성하고 OpenAI API Key를 입력합니다:
```bash
cp .env.example .env
# .env 파일에 OPENAI_API_KEY=sk-... 입력
```

### 3. 프로그램 실행

- **기본 챗봇 실행**:
  ```bash
  python chatbot.py
  ```
- **고급 CLI 챗봇 실행 (스트리밍 및 추가 명령어 지원)**:
  ```bash
  python history_chatbot.py
  ```
- **Streamlit 웹 브라우저 실행**:
  ```bash
  streamlit run history_chatbot_web.py
  ```

## 💬 대화 예시

```text
대화하고 싶은 역사적 인물을 선택하세요:
 [1] 알베르트 아인슈타인 (20세기 (1879 ~ 1955))
 [2] 세종대왕 (조선 전기 (1397 ~ 1450))
 [3] 충무공 이순신 (조선 중기 (1545 ~ 1598))
 [4] 마하트마 간디 (근현대 인도 (1869 ~ 1948))
 [5] 소크라테스 (고대 그리스 아테네)
선택 번호 (1~5): 1

✨ [알베르트 아인슈타인] 님과의 대화가 시작되었습니다!
알베르트 아인슈타인: 허허, 안녕하신가, 친구! 시간과 공간, 혹은 우주의 신비에 대해 이야기해 볼텐가? 무엇이든 물어보게나.

User: 아인슈타인, 시간 여행이 가능할까요?

알베르트 아인슈타인: 이론적으로 시간 여행은 아주 흥미로운 개념이지! 내 특수 상대성 이론에 따르면, 
빛의 속도에 가깝게 빠르게 움직이는 물체는 정지해 있는 관측자에 비해 시간이 더 천천히 흐른다네. 
즉, 미래로 향하는 시간 여행은 물리학적으로 이미 증명된 셈이지. 
하지만 과거로 돌아가는 것은 훨씬 복잡하고 인과율의 역설을 낳게 된다네. 
자네는 과거와 미래 중 어느 쪽으로 여행을 떠나보고 싶은가?
```
