# 🏦 실습 1: 초개인화 금융상품 추천 시스템 (AI응용 실습)

입력된 고객 프로파일에 대해 정밀한 맞춤 금융상품을 추천하고, 고객의 감성을 배려하는 초개인화 리포트를 생성하는 LLM 프롬프트 엔지니어링 및 비교 평가 프로젝트입니다.

---

## 📁 디렉토리 구조 및 파일 안내

- `초개인화_금융상품_추천_보고서.md`: **과제 최종 제출용 종합 보고서** (Part 1 프롬프트 설계 + Part 2 비교 평가 결과, 효과성 토의, 개선 방향 수록)
- `data.py`: 고객 프로파일 10명(C01~C10), 실습용 금융상품 10종, 모범 정답안 데이터셋
- `prompts.py`: 개발된 초개인화 시스템/유저 프롬프트 및 비교군 Minimal 프롬프트 템플릿
- `evaluate.py`: 10명 고객 대상 Minimal vs 초개인화 프롬프트 독립 세션 시뮬레이션 및 종합 메트릭 집계 스크립트
- `recommender_app.py`: 고객별 리포트 비교 및 통계를 인터랙티브하게 확인할 수 있는 터미널 CLI 프로그램

---

## 🚀 실행 및 테스트 방법

### 1. 전체 비교 평가 요약 통계 확인
```bash
python3 evaluate.py
```

### 2. 특정 고객(예: C03 싱글맘, C09 대학원생 등) 맞춤 리포트 비교 출력
```bash
# C03 이소영 고객 리포트 확인
python3 recommender_app.py C03

# C01 김은희 고객 리포트 확인
python3 recommender_app.py C01
```

### 3. 대화형 인터랙티브 CLI 실행
```bash
python3 recommender_app.py
```
